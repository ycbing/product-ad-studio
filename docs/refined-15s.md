# 15 秒精修版

在已接受的 20 秒实拍版基础上优化；原版本保留于 demo/real-product-1080p.mp4。

## 本轮变化

- 20 秒缩短到 15 秒，五镜头时长为 2 / 3 / 3 / 3 / 4 秒。
- 第一个镜头直接用罐身细节提出问题，中段交替展示收纳罐与厨房环境。
- 聚焦“透明罐身，内容可见”；不添加气密、防潮、材质安全等未验证声明。
- 开头与结尾保留主标题，中间减少大字与重复说明。
- 配音改为短句；字幕从实际音频中的说话时间开始和结束。
- 音乐在说话时自动降低，空隙缓慢恢复；收尾统一淡出。
- 主体裁切有边界限制，防止平移缩放露出画布空边。
- 将 composition 默认输入移入 src/presets，纳入 VVV 渲染输入指纹范围。

## 声音与真实性

仍使用本机 Tingting 系统配音，已调整文案和语速，不宣称是真人录音或情感模型配音。
音乐由原创合成音符构成，不引入不明来源音乐。
未添加开盖、倒入等拟音，因为当前源素材没有这些动作，避免制造虚假使用演示。
原始实拍素材、作者和许可继续见 real-footage-demo.md。
这是一条真实摄影素材制作的品类广告样片，不能替代商家特定 SKU 的素材确认。
