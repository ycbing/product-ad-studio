# 数据与任务约定

项目文档保存产品、方案、五镜头与声音开关；revision 在每次保存/选方案时增加。
素材通过 assetId 引用，只允许本项目 owner 的数据库记录；客户端不能提供磁盘路径或可执行代码。
用户上传文件不作为程序执行，实际渲染使用服务端维护的 WebStory 源码。

任务幂等键：projectId:revision:kind:shotId。并发事务先锁定项目，再插入唯一任务。
Worker 使用 FOR UPDATE SKIP LOCKED 领取任务，90 秒租约、15 秒心跳。
中断过期任务置为失败；成功素材缓存保留。付费供应商结果不明时限制重试。
每个任务携带项目修订快照，渲染产物永远关联当时的输入，而不是当前页面的可变状态。

只有当前修订存在 sample 产物时才能登记 approval；正式 render 再次检查此记录。
修改项目不删除旧产物，而是通过 revision 比较标记失效，旧确认不会授权新内容。
文件播放通过数据库记录转成 storage key，校验所有者和项目删除状态；不接受用户拼接的磁盘路径。

当前本机数据库信任认证只对 loopback 开放；此访问模式不提供远程账号体系。
本地目录与音频缓存未来迁移对象存储时需要补充租户隔离和生命周期策略。
