# 真实摄影广告样片

目标：验证真实商品材质与真实厨房环境如何接入 VVV 渲染链，替代插画式工程样片。
品类：玻璃收纳罐。未识别品牌、SKU、容量、气密性或食品接触等级；文案不作这些事实声明。
使用实拍库存素材演示品类，并不是某个商家已授权商品的正式投放片。

## 素材

两段素材均来自 RDNE Stock project，拍摄于相同厨房环境：
- https://www.pexels.com/video/glass-jars-on-the-shelf-8580867/ — 1080×1920，30fps，10.466 秒。
- https://www.pexels.com/video/glass-and-plastic-containers-on-a-kitchen-counter-8580947/ — 1920×1080，30fps，11.1 秒。

许可页面：https://www.pexels.com/license/
已核对页面允许下载、修改并用于创作广告；不能暗示素材中的人物或品牌背书。
原文件、下载来源及 SHA-256 记录于 renderer/assets.json。
不从不同商品的素材拼接出虚假的同一 SKU 使用效果。

## 制作方式

新增 RealProduct composition 与 real-product catalog；原有插画模板仍保留。
真实视频满屏排版，使用原有拍摄运动与保守缩放裁切；叠加可编辑中文文字。
五镜头共 20 秒，中文本机旁白按镜头对齐，原创合成音符作为轻量音乐底。
新增源片段范围检查；禁止 trimBefore + seconds 超出已记录的源时长。
实际继续使用 VVV 原样渲染脚本及输入指纹工具。

## 边界

实拍素材并不等于已验证某品牌商品。正式广告需替换为该 SKU 的图片、实拍或得到授权的品牌素材。
本片没有生成人物表演或伪造使用实拍；是厨房收纳场景的商品展示广告，不是演员出演的剧情片。
旁白仍使用本地系统声音；生产 TTS、声音授权、商家素材入口尚未接入。
库存视频中出现的包装和物件不表示代言或合作。
