# 四组真实商品验证

日期：2026-10-26。使用产品真实 API 上传、保存分镜、创建任务，并由独立 Worker 实际渲染。

**技术结果：4/4 完成 15 秒、1080×1920、30fps 成片。视觉结果有差异，不能用技术通过替代广告质量。**

本轮统一使用原创轻音乐、关闭旁白，主要比较素材与画面适配；未调用付费模型。
所有片子为非官方验证样片。前三款有来源页面支持的型号，法压壶只确认品类，不冒充品牌 SKU。

## 本轮发现并修复

1. 两行大标题靠近或压到商品图片：增加标题安全留白，并按文案长度调整字号；超出三行的主文案明确要求修改。
2. 横屏视频默认居中裁掉主体：新增横/纵焦点控制，并同步到网页排版预览与最终渲染。法压壶案例实际使用 70% 横向焦点。
3. 末镜商品已离开画面：修改源片段选择，回到同一原片中壶仍可见的倒咖啡时刻；没有伪造新的动作。

15 项行为/布局回归测试通过，TypeScript 检查和 Next.js 生产构建通过。

## 检查与边界

- 四条正式片 VVV 检查均通过：画幅、1080p、音轨和最长静止段。
- 三条商品图视频约 78–79% 的帧差被识别为近静态；它们是图文展示片，不能宣称为真实动态拍摄。
- 法压壶静止帧占比测量为 0；这只反映画面运动，不表示创意或商业效果优秀。
- 音频均值约 -37.4dBFS，属于较轻的背景音乐；本轮不验证人声自然度。
- 每条检查 1/4/7/10/13 秒的真实输出帧，没有宣称完成人工连续播放或听音验收。
- 导出确认由验证程序在隔离命名的验证项目中模拟，不表示商家验收。
- 原始与修复后结果分别在 ../2026-10-26/ 和本目录，源文件 SHA-256、项目修订、任务和渲染指纹在 report.json。
