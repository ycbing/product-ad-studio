# 法压壶：把早晨还给自己

[观看 1080p 成片](morning-coffee-scene-1080p.mp4) · [低清样片](morning-coffee-scene-sample.mp4) · [五镜头预览](storyboard.jpg) · [完整抽帧检查](full-frame-review.jpg) · [工作台截图](studio-scene-preview.png)

18.5 秒，1080 × 1920，30fps。使用四段同系列的真实实拍素材。不是品牌委托广告，不确认制造商或具体 SKU；没有生成商品、背景或人物动作。

## 从固定图卡改为真实场景

1. 厨房准备：建立人物和生活环境，开场只留一句文案。
2. 窗边注水：保留真实水流、壶身、杯子与手的操作；不覆盖大标题。
3. 倒咖啡：用较宽的角度建立动作关系。
4. 倒出细节：切到更近的视角，仅留一句小字幕。
5. 放下法压壶、端杯：用实际动作收尾，文案“把早晨还给自己”。

不靠换背景色制造差异。场景来自实拍，剪辑顺序由人工匹配；两段倒咖啡画面按同一动作的不同视角剪辑，不声称它们是严格时间同步的双机拍摄。

## 同步到产品的改动

- 铺满画面的场景镜头不再显示固定卡片、镜头编号、默认品牌和重复大标题。
- 每镜可选标题、仅字幕或纯画面，支持放大与横纵裁切焦点；预览使用同样设置，视频循环限定在所选片段内。
- 默认保留素材的画面运动，不对所有实拍强制添加统一缩放。
- 剪辑草稿按输入视频顺序组织，重复源分配不同起点，避免每镜从零重复，也不在结尾跳回第一个环境镜头。
- 只有照片时明确提示“图文展示片”；提示补充环境、操作与结果视频。自动草稿尚未识别具体动作，需要逐镜核对。
- 有原音轨的素材可设置音量，配音时降低原声。本轮源视频没有音轨，成片使用已有原创合成配乐；没有真实倒水声，未验证实录原声效果。

## 验证情况

通过实际产品 API 上传、保存分镜、创建样片、测试确认门槛、正式导出；本机项目保留可编辑。

- 20 项测试通过，TypeScript 检查和 Next.js 生产构建通过。
- VVV 画幅、分辨率、音轨和静止段检查通过；测得近静态帧占比为 0。这些只反映技术属性，不表示广告效果获得商业认可。
- 检查 0.5–18.3 秒之间 17 张实际 1080p 输出帧，覆盖每个切点前后；另检查工作台的注水镜头预览。
- 首轮画面中壶身/手柄被裁切，再将注水焦点改为 88%、较宽倒出角度改为 78%、收尾改为 90%，重新完成样片和正式渲染。
- 没有宣称完成连续看片、听音或商家验收；本次导出确认由隔离验证程序完成，旁白关闭，无付费模型调用。

自动语义理解、单图生成同款商品的真实交互视频、复杂人物剧情与自动口型仍未实现。这轮验证的是以真实素材为基础的生活场景剪辑，不是上述生成能力。

## 来源与复现

素材由 Taryn Elliott 发布于 Pexels，详见 [每段来源、许可、修改及哈希](morning-coffee-scene-sources.md)。原始素材无音轨；原创合成配乐按 CC0 提供。来源页与许可不构成作者或品牌为样片背书。

原始文件放入 `REAL_PRODUCTS_ASSET_DIR`，文件名与 `fixtures/scene-coffee.json` 一致；本地启动数据库、Web 和 Worker 后运行：

```sh
REAL_PRODUCTS_ASSET_DIR=/absolute/path/to/assets \
REAL_PRODUCTS_FIXTURE=fixtures/scene-coffee.json \
VALIDATION_RUN_ID=your-new-run \
npm run validate:products
```

这条命令只用于自己的本机隔离验证项目，不应在商家生产项目上模拟确认。
